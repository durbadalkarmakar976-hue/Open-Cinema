# OpenCinema — Free Legal Movie Website Starter

A simple, responsive static movie catalogue. It includes search, genre filtering, and links to official Blender Open Movies pages for Big Buck Bunny, Sintel, and Tears of Steel.

## Run it locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

## Publish free
### GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example `opencinema`.
3. Upload `index.html` and this README.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will show the public website URL after publishing.

Hosting provider features and steps may change; follow the current on-screen GitHub Pages instructions.

## Before launch
- Replace the demo brand and add your contact/about/privacy pages.
- Check each film's current licence and required attribution before promoting it.
- Do not upload or mirror movies unless the rights holder's licence explicitly allows redistribution.
- Pinterest: use original graphics and descriptions, link to relevant pages, avoid spam/repetitive Pins, and verify that your destination URL is accepted.
- Advertising income is not guaranteed. Ad networks may require a privacy policy, original content, and site review.
- This starter does not collect user data and has no login, database, or ad code.

## Customise
Edit the film cards in `index.html`. Each card has `data-title`, `data-genre`, a title, description, and official-source link.
